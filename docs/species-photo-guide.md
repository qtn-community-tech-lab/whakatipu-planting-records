# Species photo guide

The app’s **Species → Top 50 species guide** page (`/species/photos`) shows the fifty species with the highest recorded plant quantities across all sites and seasons. Profiles and reviewed photo sets cover all 50. This includes quantities on records needing review, rather than treating them as verified plantings. At the 4 October 2026 profile expansion, the top 50 totalled **134,846 of 140,068 recorded plants (96.3%)**. The guide ranks the current dataset; ties use botanical names. Coverage tests flag changes to the top 50 profiles and photos for editorial review.

The main Species page shows a thumbnail beside each covered name, with its credit, licence and source link. Each covered species detail page also displays its reference photo. Each of the fifty species now has **three distinct reference images**, 150 in total (148 Wikimedia Commons and two iNaturalist). Whole plants, foliage, flowers, fruit or bark are included where sources allow; the Austroderia richardii, Coprosma dumosa and Coprosma linariifolia sets each include one explicitly labelled museum herbarium specimen. The shared catalogue is keyed to WRT’s species IDs. Contested names remain separate; choosing an image does not make a taxonomic ruling or alter planting data.

### Name gaps within the covered 50

Fifteen profiles have no verified Māori name in the sources checked. An empty list means research remains open; it does not establish that no Māori name exists:

Olearia odorata, Olearia lineata, Olearia fimbriata, Coprosma rugosa, Olearia hectorii, Olearia bullata, Coprosma rigida, Aristotelia fruticosa, Veronica odora, Coprosma intertexta, Melicytus alpinus, Poa colensoi, Veronica cupressoides, Carex buchananii, Olearia fragrantissima.

Two profiles also lack a verified common name: Coprosma rigida, Coprosma intertexta. Preserve the explicit fallback rather than inventing a name. Names from the historical register and shared names are not automatically species-specific confirmations.

### Register entries outside the planting-history listing

The full transformed register contains **164 entries**, including **69 without any planting-history rows**. Those 69 are outside the current 95-entry species listing and the planting-quantity ranking. They are a separate backlog if the guide is expanded to cover the entire register; absence from this transformed history does not prove a species was never planted. Some entries may represent alternate names or spelling variants, so review identity before creating new profiles.

### Evidence and update procedure

- Rank and quantities: [planting_history.csv](planning/prototype/planting_history.csv), grouped by `species_id_proposed` and sorted by descending total quantity, then database botanical name for ties.
- Names, flags and register-only entries: [species_master_proposed.csv](planning/prototype/species_master_proposed.csv). An entry is included in the 95 if it has a history row, even when its quantity is zero.
- Reference coverage and name gaps: [species-profiles.json](../data/species-profiles.json) and [species-photos.json](../data/species-photos.json), joined by species ID.
- Automated coverage checks: [species-profiles.test.ts](../tests/species-profiles.test.ts) and [species-photos.test.ts](../tests/species-photos.test.ts). They check exact top-50 membership, botanical-name matching and three distinct photo sources per covered species.
- After changes to history, identities or references, recompute this dated audit and update the table and totals. Keep source links, licence metadata and the check date; flag unresolved identity questions before attaching references.

## Species names and identification profiles

All fifty species have a reference profile in `data/species-profiles.json`, shown in the photo guide and on each species detail page. The main `/species` listing also displays the reviewed common and Māori names and a short description directly in each covered card. “Identification & sources” expands the identification features, name notes and source links without leaving the listing. Each includes a botanical name, common name, documented Māori names, a short description, identification features, source links and a check date. These are manually reviewed summaries, primarily from Wikipedia, with New Zealand botanical references for gaps. No Wiki MCP was available. Olearia lineata uses NZPCN and the Flora of New Zealand; Olearia fimbriata uses a DOC factsheet. WRT’s own planting guide supports the narrow-leaved tree daisy common name.

An unverified common name is stored as `null` and gets the same explicit fallback as Māori names; the profile title uses the botanical name. An empty Māori-name list displays “Not recorded in the sources checked.” It does not mean no Māori name exists. Shared names are explained, including kōwhai, toetoe and mingimingi/mikimiki. Carmichaelia petriei’s WRT name Mākaka is explicitly marked as a shared broom name without species-specific confirmation. Macrons are retained in display text. Profiles remain separate from WRT’s historical species register and do not change names, quantities or disputed taxa. The Olearia lineata and Olearia bullata profiles note NZPCN’s newer Shawia names while retaining the database names. Wikipedia’s mountain-flax article uses Phormium colensoi; the profile explains the alternative Phormium cookianum name without assigning an unrecorded subspecies. Poa cita’s possible southern name Pātītī is qualified as such, following Ngā Rauropi Whakaoranga. Hoheria glabrata has verified shared names Houhere, Houhi and Houi, and explains that the register’s Whauwhau was not confirmed in the checked references.

The ranks 36–50 extension adds verified Haumata, Tarata, Tūmatakuru, Putaputawētā and other names. Horoeka is explicitly shared by the two lancewoods; Akeake and Tauhinu are also qualified as shared names. NZPCN’s newer Shawia avicenniifolia and Shawia fragrantissima names are explained without changing WRT’s historical Olearia IDs. Veronica cupressoides has no suitable individual Wikipedia article, so its profile and photo species-reference link use NZPCN. The cypress-hebe photo set excludes the ornamental cultivar “Broughton Dome”.

Profile text is bundled with the app; it makes no live Wikipedia request. The source URLs remain available for review and future updates. Hosted reference images still need internet access. To extend coverage, review names and identification details against the species-specific sources, add a profile keyed to the correct species ID and run the coverage tests.

## Photo sources and reuse

`data/species-photos.json` holds the reviewed species mapping, caption, photographer, licence and licence link, Wikimedia Commons file page, Wikipedia article, hosted image URL and source-check date. The browser loads the source-hosted thumbnails directly using `next/image` with `unoptimized`; the app does not download, cache or resize them on its server. No image binaries are committed. Image viewing needs internet access and depends on source availability; planting data stays local. Credits, licence links and source links appear with every photo.

Candidates came from Wikipedia’s lead images and Wikimedia Commons species categories, using the public [PageImages](https://www.mediawiki.org/wiki/Extension:PageImages) and [Imageinfo](https://www.mediawiki.org/wiki/API:Imageinfo) APIs. There was no installed Wiki MCP. Candidate selection was checked against the Commons file descriptions rather than accepting the article’s lead image blindly:

- Olearia lineata and Olearia fimbriata have Commons photos even though their articles returned no lead image.
- Austroderia richardii uses the species-labelled Port Hills photo instead of the Milford Sound photo labelled only “Austroderia sp.”
- Corokia cotoneaster uses a photograph rather than the article’s botanical illustration.
- Podocarpus laetus retains the already-cropped Wiki source and mentions that in its caption.
- The ranks 36–50 source checks are retained in `data/photo-source-evidence/commons-top50.json`. Coprosma linariifolia has two living-plant photos and a labelled Auckland Museum herbarium specimen (AK362659).
- The ranks 21–35 source checks are retained in `data/photo-source-evidence/commons-top35.json`. Phormium cookianum images are catalogued under Phormium colensoi on Commons; Fuscospora fusca sources use Nothofagus fusca, which is stated in the photo captions. Coprosma dumosa has two living-plant photos and a labelled Auckland Museum herbarium specimen (AK360802).

These are illustrative reference photos taken at other locations. They are not evidence of a planting, its survival, a site identification or its current condition. The app uses rounded, cropped previews with an adjustable focal point to fit the Canopy theme. Full image links open the complete source-hosted reference. Thumbnail files were resized by their source; the app does not edit the downloaded assets. Each asset remains under its stated CC BY, CC BY-SA, CC0 or public-domain terms; see the linked source for full licence details. There is no blanket relicensing of these photos under an application licence.

The catalogue retains the image URLs, dimensions, species mapping and complete attribution so the same references can be downloaded for offline display later. Offline support is not enabled now. A later download process should verify that the source image and licence still match, save the files locally and retain the same credits. To extend coverage now, select a species-labelled reference, check its licence and attribution, add its hosted URL and metadata, and run the catalogue tests.

## Olearia hectorii fallback

Wiki’s species category (spelled “Olearia hectori”) and article provided only one suitable photo. With the user’s approval to use other openly licensed sources, two complementary photos of flower buds and bark were selected from John Barkla’s [research-grade iNaturalist observation](https://www.inaturalist.org/observations/60402502). The API identifies the taxon as Olearia hectorii (404278) and the individual photos as CC BY. The official [iNaturalist licence module](https://github.com/inaturalist/inaturalist/blob/main/app/models/shared/license_module.rb) maps CC BY to version 4.0. Photo-level attribution and source evidence are saved in `data/photo-source-evidence/inaturalist-hectorii.json`; observation coordinates are not copied into the project. Source labels distinguish these photos from Wiki references.

## Browsing sublocations

Site pages link each entry in **Parts of this site** to the records page with both the parent site and exact parcel ID in its URL. The **Part of site** filter lets you switch between registered sublocations or return to all parts. Sorting, pagination and CSV downloads retain that selection; changing or removing the parent site clears it. A species summary shows the selected part’s recorded quantities, including unresolved records. Searching a site-group alias is not a reliable sublocation filter.

The species names link to their detail pages and reference photos where available. A future photo view for a selected sublocation can reuse this catalogue alongside any unresolved source/location notes. The separate wetlands walkthrough has been removed; its earlier version remains in the baseline commit.
