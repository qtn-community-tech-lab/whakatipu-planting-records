# Restore local documentation

The `docs/` directory is excluded from this repository because it contains client documentation and workbook-derived data. To restore it for local work:

1. Download or copy the contents of the shared Google Drive folder: [Client documentation](https://drive.google.com/drive/folders/13_jeLGxdwGMCy4ZJUO27X-KoThnqbZ6M?usp=share_link).
2. Place the downloaded `docs` directory in the repository root, alongside this file.

The local `docs/` directory is ignored by Git and will not be committed or pushed.
